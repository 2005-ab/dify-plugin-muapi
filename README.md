# Dify Plugin — MuAPI

## Overview

MuAPI is a generative media platform that provides access to 100+ AI models for image, video, and audio generation through a single API. Models include FLUX, Midjourney, GPT-4o, Veo3, Kling, HunyuanVideo, Runway, Suno, and more. Check all models [here](https://muapi.ai/models).

This plugin integrates MuAPI's models into Dify, enabling developers to use state-of-the-art generative media models directly inside Dify workflows and applications.

## Configuration

1. [Sign up for MuAPI](https://muapi.ai) or log in to your existing account.
2. Open your [API Keys](https://muapi.ai/dashboard/keys) page.
3. Click **Create API Key** to generate a new key.
4. Configure in Dify: Open **Settings → Model Provider**, find **MuAPI**, and enter your API key in the API Key field.
5. Click **Save** to activate the plugin. You can now use MuAPI models in your Dify workflows.

Source code of this plugin: <https://github.com/SamurAIGPT/dify-plugin-muapi>
